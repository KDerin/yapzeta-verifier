# Security policy

## Scope

This research preview contains a standalone Python verifier. It does not include the YAPZETA service, private indexes, research corpora, model weights, credentials, or deployment configuration.

## Reporting a vulnerability

Do not report exploitable vulnerabilities in public issues. Contact the maintainer through a verified private channel listed on the maintainer’s official profile or repository. Include affected version, reproduction steps, impact, and any mitigation. Do not attach real personal data, API keys, private academic materials, or complete proprietary indexes.

No private reporting address has been verified. Before public release, enable GitHub private vulnerability reporting or provide a verified maintainer-controlled private channel.

## Security notes

- Treat evidence text and metadata as untrusted input.
- Do not send API keys or credentials in claims, chunks, test output, issues, or logs.
- Optional ONNX/tokenizer model files are external and must be sourced and reviewed separately.
- The software has not undergone a security audit.
